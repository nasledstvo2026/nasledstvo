# skill-standards

Стандарты написания SKILL.md под OpenClaw. Адаптация effective-agent-skills от David Ondrej.

## Структура скилла

Папка — `lowercase-hyphen`, имя класса задачи (`<домен>-<задача>`), а не разовый запуск.

```
my-skill/
├── SKILL.md          # Обязательно: frontmatter + инструкция
├── references/       # Опционально: подробные документы, загружаются по необходимости
├── scripts/          # Опционально: вспомогательные скрипты
└── examples/         # Опционально: примеры использования
```

## SKILL.md frontmatter

```yaml
---
name: skill-name
description: Что делает скилл И когда его использовать. Включай триггер-фразы. Ориентир — до 160 символов.
---
```

## Progressive disclosure

- **Level 1** — discovery: только `name` + `description` из frontmatter в системе. Агент знает что скилл есть.
- **Level 2** — activation: при совпадении запроса агент читает полный SKILL.md в контекст.
- **Level 3** — execution: агент читает references/ скрипты только когда нужно. Они не жрут контекст до востребования.

## Правила

1. **Описание в frontmatter — краткое и ёмкое.** Включает: что делает + когда включать (триггеры). Ориентир — до 160 символов; если у скилла несколько разных триггеров, перечисли их, не теряя смысл.
2. **Тело SKILL.md — конкретные инструкции.** Без воды, без общих слов. Шаги, команды, форматы.
3. **Сложное и объёмное — в references/.** Не пихать в тело SKILL.md базы знаний на 500 строк. Сделать `references/foo-knowledge.md` и сослаться. Одну фразу в отдельный файл не выносить: файл должен сокращать чтение, а не добавлять переход.
4. **Примеры — в examples/.** Короткий пример в теле, полный — в файле.
5. **disable-model-invocation: true** — если скилл не требует вызова модели (чисто процедурный). Экономит токены.
6. **`name` = имя папки** дословно — по нему скилл и находится; так во всём наборе.
7. **Описание платит контекстом при каждом запуске.** В нём только «что делает + когда включать»; пересказ шагов, цифры и внутренние подробности — в теле. Разросшееся описание (300+ символов) почти всегда дублирует тело.
8. **Путь к файлу вне папки скилла — однозначный.** Не `knowledge/...`, если таких корней несколько (у каждого агента свой workspace): писать от корня агента или абсолютным путём.
