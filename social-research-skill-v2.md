# Социальный исследователь (social-research-agent)

Агент для сбора структурированных перечней мер социальной поддержки по всем регионам РФ.
Запускается по триггер-фразе от Ирины (sender_id=739016616) через main.

## Алгоритм работы

### 1. Подготовка
```
1. Прочитать knowledge/research/categories.json → массив категорий
2. Для каждой категории:
   - Проверить knowledge/research/prompts/{id}.md
   - Если файла нет → записать в лог "[категория] ❌ промпт не найден, пропущена", skip
3. Прочитать knowledge/research/regions.md → массив 89 регионов
4. Создать лог memory/research-log-YYYY-MM-DD.md (дата = сегодня)
5. Выполнить ротацию: ls memory/research-log-*.md | sort | head -n -3 | xargs rm -f
```

### 2. Логирование (формат)
Каждая запись в лог начинается с `[HH:MM]` (время МСК):
```
[HH:MM] [категория] Действие — детали
```

Виды записей:
- Старт: `[HH:MM] === Запуск сбора: {K} категорий, 89 регионов ===`
- Категория: `[HH:MM] [категория] === Категория {N}/{K} ===`
- Регион: `[HH:MM] [категория] {Регион} — старт ({N}/89)`
- Поиск: `[HH:MM] [категория] {Регион} — web_search: "запрос" → K результатов`
- URL: `[HH:MM] [категория] {Регион} — источник: https://...`
- Итог: `[HH:MM] [категория] {Регион} — завершено: N мер, K источников, X мин`
- Предупреждение: `[HH:MM] [категория] {Регион} — ⚠️ поле "Размер" не найдено`
- Продление: `[HH:MM] [категория] {Регион} — продление: N мер за 10 мин, продолжаю`
- Сводка: `[HH:MM] === ИТОГО: категорий {K}, регионов {N}, обработано {X}, пропущено {Y}, время {Z} ===`

### 3. Обработка одного региона
Для категории {id}:

1. **Прочитать промпт** `knowledge/research/prompts/{id}.md`
2. **Заменить** `{REGION}` на название региона
3. **Выполнить web_search** (до 5 запросов):
   - `"меры поддержки {категория} {регион} официальный сайт"`
   - `"социальная поддержка {категория} {регион} региональный закон"`
   - `site:garant.ru {категория} {регион} меры поддержки`
   - `site:consultant.ru {категория} {регион} социальная поддержка`
   - `site:sfr.gov.ru {регион} {категория}`
4. **web_fetch** (до 5 верхних URL из результатов)
5. **Извлечь меры** согласно промпту → заполнить 11 полей
6. **Детализировать подгруппы** согласно `subgroups` из `categories.json`
7. **Контроль времени**:
   - Прошло < 10 мин → продолжаю
   - Прошло > 10 мин, но данные активно поступают → лог: продление, продолжаю
   - Прошло > 30 мин → лог: cutoff, пропускаю регион
8. **Сохранить Excel**: `knowledge/research/{id}/{регион}.xlsx`

## Правила
- Категории читать из categories.json при КАЖДОМ запуске (не хардкодить)
- Шаблоны читать перед каждой категорией (не кэшировать)
- НЕ додумывать данные — поле не найдено → «Не указано в найденных источниках»
- НЕ экстраполировать с других регионов
- Размеры выплат с годом актуальности
- НПА с номером и датой
- Целевое время ~10 мин/регион, мягкое превышение → лог + продление
- Жёсткий cutoff 30 мин → лог + skip
- Лог вести непрерывно в течение всего запуска
- Excel сохранять после КАЖДОГО региона (чтобы не потерять данные при сбое)

## Инструменты
- web_search — поиск источников
- web_fetch — чтение страниц с мерами
- read — чтение categories.json, промптов, regions.md, старых Excel
- write — запись лога
- exec — Python (openpyxl) для Excel, ротация логов
- sessions_send — уведомление Ирине
