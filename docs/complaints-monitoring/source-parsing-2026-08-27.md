## Ключевые технические факты

1. **banki.ru: rate-limit подтверждён и обходится троттлингом.** Агрессивный режим (78 запросов за 9 с)
   → бан `http=000` на ~1,5 часа. Режим 1 запрос / 2 с: **55 карточек подряд без единого отказа**.
2. **Объём banki.ru за сутки:** страница 1 = 26–27.08, страница 6 = 25.08 → ~2–3 страницы,
   т.е. **50–75 отзывов/сутки**. Тема в листинге не видна (заголовки вида «Отзыв», «Перевод»),
   поэтому нужен двухступенчатый разбор: листинг → все карточки за сутки (~2–3 мин при троттлинге 2 с).
   Опция сужения: фильтр `?rate[]=1&rate[]=2` (плохие оценки) работает, но может срезать
   часть наследственных жалоб с нейтральной оценкой — применять с осторожностью.
3. **pravoved.ru — самый «плотный» по теме, но с коротким окном.** В свежей ленте тематических
   ~20 % (1 из 5 проверенных: вопрос №5030643 от 27.08.2026 18:34 — «Как наследнику получить
   документы умершего и открыть наследственное дело без паспорта наследодателя»). Пагинации нет →
   **опрос раз в сутки теряет поток**, нужен цикл каждые 2–4 часа. Поиск по релевантности отдаёт
   архив 2016–2021: пилот сразу нашёл **17 тематических вопросов, которых нет в базе** — это готовый
   материал для исторического бэкфилла, а не для ежедневной сводки.
4. **pikabu.ru** пригоден только на уровне ленты тега: заголовок + дата + сниппет. Полный текст
   поста без headless-браузера недоступен (проверено на посте
   `vtb_ne_vyidal_naslednitsam_vklad_umershego` — 201 КБ, 392 слова, тема в тексте не извлекается).
5. **otzovik.com** — обратная картина: карточки читаются, но нет способа узнать, какие карточки
   появились сегодня, кроме разбора 274 gzip-sitemap без дат. Для ежедневного мониторинга непригоден.
6. **Пилот целиком:** 85 запросов, **217 секунд**, 0 LLM-токенов. Для сравнения текущий
   `search-agent`: медиана 292 с, максимум 977 с, ~0,9 М cache-токенов на прогон, при этом за сутки
   он просматривает лишь верхушку выдачи.

## Что это значит для решения по FR-01

Рабочий состав источников для ежедневного мониторинга:

- **ядро:** banki.ru (двухступенчато) + pravoved.ru (лента, опрос 2–4 раза в день);
- **дополнительно:** pikabu.ru (тег, классификация по заголовку/сниппету), advgazeta.ru (новости);
- **вывести из ежедневного цикла:** sravni.ru (пусто по теме), 9111.ru (блок IP), otzovik.com
  (нет навигации по свежести — оставить как ручной/бэкфилл-источник), asn-news.ru (тем нет), kp.ru;
- **разово:** бэкфилл pravoved.ru по поисковым запросам (17 найденных вопросов + расширение
  списка запросов).

Покрытие такого состава по текущей базе: banki.ru 91 + pikabu 17 + pravoved 6 + advgazeta 1 = **115
из 124 записей (93 %)**.

## Ограничения проверки

- Частоту наследственных жалоб на banki.ru измерить точно не удалось: за проверенные 55 карточек
  (~сутки) тематических нет; по базе — 1–2 в неделю. Нужен пилот на 7 дней, чтобы получить честную
  оценку полноты.
- Пробы делались с одного IP VPS; поведение сайтов может отличаться при других IP/UA.
- Для pikabu и otzovik вывод «текст недоступен» верен для curl без JS; headless-браузер
  (плагин canvas/browser) вопрос решает, но это отдельная инфраструктура и отдельная стоимость.
