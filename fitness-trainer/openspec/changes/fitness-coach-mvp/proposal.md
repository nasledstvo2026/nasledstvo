# Change: Персональный ИИ-тренер для тренажёрного зала (MVP)

## Why

Большинство взрослых (18–60) занимаются в зале без системного плана: случайные программы из интернета, без учёта сидячего образа жизни, возрастных изменений суставов и хронических ограничений. Очные персональные тренировки дороги, а базовые фитнес-приложения не ведут живой диалог и не адаптируют нагрузку безопасно.

Нужен автономный ИИ-консультант в Telegram на базе OpenClaw, работающий на доказательной спортивной медицине (ACSM, NSCA, NASM, ISSN) и принципах возрастной физиологии.

## What Changes

- Появляется агент-консультант «Вася», который ведёт живой диалог, строит и адаптирует тренировочные планы.
- Появляется агент-верификатор, который проверяет каждый совет Васи до выдачи пользователю.
- Новый цикл: онбординг со скринингом → профиль клиента → генерация программы → адаптация по RPE/замене упражнения → верификация совета → доставка.
- BREAKING: нет (зелёное поле).

## Capabilities

### New

- onboarding-screening — возрастной ценз 18–60 (self-report + дисклеймер), медицинский скрининг (PAR-Q+), детекция красных флагов.
- client-profile — долговременная память клиента: травмы, ограничения, оборудование зала, рабочие веса.
- program-generation — построение программы по сегментам 18–44 / 45+ на основе стандартов.
- workout-adaptation — корректировка плана по RPE после тренировки, безопасная замена упражнений при дискомфорте.
- safety-disclosure — отказ при противопоказаниях, направление к врачу, дисклеймер «не врач».
- advice-verification — обязательная проверка верификатором каждого совета Васи до доставки.

## Impact

- Affected specs: 6 новых capability-спек.
- Agents: Вася (консультант), верификатор.
- Память: долговременный профиль клиента.
- Риски: медицинская ответственность, безопасность пользователя (Zero Harm).
