# ТЗ: мониторинг страховых случаев АСВ — критерии и источники

**Проект:** `monitoring/asv-agent`
**Редакция:** 3 от 11.11.2026
**Область:** только критерии отбора/принятия решения о страховом случае и перечень источников данных

---

## 1. Критерии отбора события

Кандидатом в «страховой случай» считается публикация, удовлетворяющая **всем** критериям K1–K5.

| № | Критерий | Проверка |
|---|---|---|
| **K1** | Публикация на официальном сайте АСВ (asv.org.ru), раздел «Новости»; при ручной проверке — также «Интерфакс об Агентстве» | поле `url`/секция ответа API |
| **K2** | Заголовок прямо содержит формулировку о наступлении страхового случая: «О наступлении страхового случая…», «…наступлении страхового случая…» | нормализованный заголовок (`&nbsp;`→пробел, lower-case), подстрочное совпадение |
| **K3** | Дата публикации не старше 30 дней от момента прогона | поле `date` формата `ДД.ММ.ГГГГ` |
| **K4** | Событие ранее не обрабатывалось (нет `id` в `seen.json`) | дедуп по `id` новости |
| **K5** | Событие относится к банку — участнику ССВ: есть отзыв лицензии, назначение временной администрации или начало выплат АСВ | заголовок + текст новости / второй источник |

**Дополнительно:** один страховой случай = один банк + дата решения. Несколько публикаций по одному банку дают один алерт, а не серию.

---

## 2. Критерии исключения (не страховой случай)

Публикация **не** признаётся страховым случаем, если выполняется хотя бы одно условие:

| № | Исключение | Пример формулировки |
|---|---|---|
| **И1** | Исключение банка из ССВ после завершения ликвидации — рутина | «Об исключении банка из числа участников ССВ» |
| **И2** | Конкурс по отбору банков-агентов без нового страхового случая — отдельный класс KONKURS | «Конкурс по отбору банков-агентов…» |
| **И3** | Судебные и процедурные новости: торги имущества, собрания кредиторов, субсидиарная ответственность | «торги», «собрание кредиторов», «субсидиарная» |
| **И4** | FAQ / разъяснения / вопросы-ответы | раздел `vopros-otvet` |
| **И5** | Публикация старше 30 дней или уже обработанная | `date`, `seen.json` |
| **И6** | Анонс, план мероприятия, статистика или отчёт без факта отзыва лицензии | «состоится», «итоги года», «отчёт» |

Исключённые публикации помечаются увиденными, чтобы не возвращаться к ним повторно.

## 3. Правило принятия решения

Решение принимается в три уровня.

### 3.1. Уровень A — «подтверждён»
Событие считается страховым случаем, если одновременно:
1. выполнены K1–K5;
2. в заголовке есть прямая формулировка о наступлении страхового случая;
3. есть подтверждение факта: отзыв лицензии решением ЦБ РФ, назначение временной администрации или сообщение АСВ о начале выплат;
4. не сработало ни одно исключение И1–И6.

**Действие:** алерт Кириллу в течение 12 часов; в алерте — банк, дата, заголовок, ссылка на новость АСВ, пометка «страховой случай подтверждён».

### 3.2. Уровень B — «вероятен»
Заголовок соответствует K2, но факт отзыва лицензии не подтверждён в тексте или нет второго источника.

**Действие:** обязательная проверка перед алертом — сайт ЦБ РФ (раздел об отзыве лицензий) и/или профильный материал СМИ (banki.ru, «Ъ»). Если подтверждение найдено → уровень A. Если нет → событие отклоняется и помечается обработанным, без алерта.

### 3.3. Уровень C — «отклонён»
Сработало исключение И1–И6, либо K1–K5 не выполнены, либо подтверждение не найдено за один цикл проверки.

**Действие:** без алерта; `id` записывается в состояние.

### 3.4. Формальная логика

```
if not (K1 and K2 and K3 and K4 and K5):        -> C
if any(I1..I6):                                 -> C
if title_has_insurance_event and fact_confirmed -> A
if title_has_insurance_event and not confirmed  -> B (проверка; затем A или C)
else                                            -> C
```

**Источник истины:** АСВ. СМИ — только ускоритель и кросс-проверка; при расхождении приоритет у asv.org.ru.

## 4. Перечень источников данных

### 4.1. Основной источник (автоматический)

| Параметр | Значение |
|---|---|
| Источник | Официальный сайт АСВ — поисковый API |
| Endpoint | `POST https://www.asv.org.ru/api/v1/` |
| Тело запроса | `{"action":"search.getList","q":"<фраза>","lang":"ru"}` |
| Заголовки | `Content-Type: application/json`, браузерный `User-Agent` |
| Рабочие разделы | `novosti`, `interfaks-ob-nbsp-agentstve` |
| Исключённый раздел | `vopros-otvet` (FAQ-шум) |
| Поля ответа | `id`, `date` (`ДД.ММ.ГГГГ`), `title`, `url` (`/news/<id>/`) |
| Таймаут | 30 с |
| Статус | единственный источник для автоматического мониторинга |

**Поисковые фразы:**
1. `наступлении страхового случая`
2. `конкурс по отбору банков-агентов` (смежный класс KONKURS, не страховой случай)

**Ограничения источника:**
- сайт — JS-SPA: `/news`, `/rss`, `/sitemap.xml` отдают каркас ~345 байт, HTML не парсить;
- поиск ранжирует по релевантности, а не по дате — обязателен фильтр K3;
- формулировки заголовков могут меняться — K2 требует периодической сверки.

### 4.2. Источники подтверждения (ручные / по требованию)

| Источник | Что даёт | Режим |
|---|---|---|
| **cbr.ru** — раздел отзыва лицензий | официальное решение ЦБ, дата и номер приказа | верификация уровня B → A |
| **asv.org.ru** — страница новости | полный текст: банк, начало выплат, временная администрация | верификация K5 |
| **banki.ru** RSS `https://www.banki.ru/xml/news.rss` | самая регулярная перепечатка новостей АСВ, суть в `<description>` | кросс-проверка, ускорение |
| **kommersant.ru** RSS `https://www.kommersant.ru/RSS/news.xml` | суды, уголовные дела, крупные отзывы | кросс-проверка |
| **РБК, ТАСС, Интерфакс, Лента** | подтверждение резонансных случаев | грепом по «АСВ», «страховани[ея] вкладов», «страхового возмещения», «отзыв.*лицензи» |

**Ограничения вторичных источников:**
- `web_search` в runtime отключён — используются только прямые RSS/API;
- страницы статей banki.ru через `web_fetch` отдают баннер — читать из RSS;
- СМИ могут опережать АСВ и ошибаться в деталях → не являются основанием для уровня A без подтверждения АСВ/ЦБ.

### 4.3. Что источниками не является
- соцсети, Telegram-каналы, форумы — без верификации;
- агрегаторы без первоисточника;
- кэш поисковых систем.
