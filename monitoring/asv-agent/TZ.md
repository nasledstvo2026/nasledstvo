# ТЗ: автомониторинг новостей АСВ

**Проект:** monitoring/asv-agent · **Согласовано:** 17.09.2026 · **Действует до:** 31.12.2026

## 1. Цель
Раньше всех узнавать о двух типах событий АСВ, влияющих на выбор банка-агента и на выплаты вкладчикам.

## 2. Предмет наблюдения
- **KONKURS** — конкурс по отбору банков-агентов для выплаты страхового возмещения.
- **STRAKH** — наступление страхового случая (отзыв лицензии у банка-участника ССВ).
Больше ничего не алертим (новости о торгах, судах, субсидиарке — шум для этой задачи).

## 3. Источник
Поисковый API сайта asv.org.ru: `POST https://www.asv.org.ru/api/v1/` с телом
`{"action":"search.getList","q":"<фраза>","lang":"ru"}`, раздел `novosti`.
Закрывает и конкурсы, и отзывы лицензий (АСВ публикует страховой случай в день отзыва).
HTML сайта не парсим: это JS-SPA, отдаёт пустую оболочку.

## 4. Запросы
1. «конкурс по отбору банков-агентов»
2. «наступлении страхового случая»

## 5. Алгоритм
1. Забрать оба запроса, собрать items в словарь по id.
2. Классифицировать по заголовку (после замены `&nbsp;` на пробел, lower-case):
   содержит «конкурс по отбору банков-агентов» → KONKURS; содержит «наступлении страхового случая» → STRAKH.
3. Дедуп: id, которого нет в `seen.json`.
4. Свежесть: дата события не старше 30 дней (защита от ранжировочных хвостов поиска).
5. Все увиденные id записать в `seen.json`; нерелевантные тоже помечаются, чтобы не всплывали.
6. Первый запуск = базовый срез: всё помечается увиденным, алертов нет.

## 6. Формат вывода (stdout)
- `CLEAN` — новых событий нет.
- `KONKURS|ДД.ММ.ГГГГ|заголовок|/news/xxxxxxx/`
- `STRAKH|ДД.ММ.ГГГГ|заголовок|/news/xxxxxxx/`
Ошибки — в stderr, exit code 0; state при сбое сети не затирается.

## 7. Доставка
Два крона, sessionTarget=main, systemEvent:
- `asv-agent-monitor-morning` — 09:00 МСК (`0 9 * * *`, Europe/Moscow)
- `asv-agent-monitor-evening` — 19:00 МСК (`0 19 * * *`, Europe/Moscow)

Агент запускает `python3 …/check.py`. CLEAN → ровно `NO_REPLY`. Строки KONKURS/STRAKH → короткий алерт Кириллу: тип, дата, заголовок, ссылка `https://www.asv.org.ru{url}`; для STRAKH — примечание, что конкурс банков-агентов ожидается в течение недели.

## 8. Надёжность
- Бэкапы: `backups/check.py.bak-*`, `backups/seen.json.bak-*`, `backups/crons.json` (id/расписание/payload).
- Env-переключатели `ASV_API`, `ASV_STATE` — тесты без сети и без порчи прод-state.
- `test_e2e.py` (мок fetch): свежие KONKURS+STRAKH алертятся, шум и старьё отсекаются, дедуп → CLEAN, недоступный API → ERR, state цел. Все PASS.

## 9. Границы
Не делает: не мониторит ЦБ напрямую, не отслеживает новости СМИ, не ведёт список аккредитованных банков-агентов.
Проверить в конце декабря 2026: продлить или отключить.

## 10. Ручной режим (когда спрашивают «что по новостям про АСВ»)
Дополнительно к check.py: API-поиск asv.org.ru по «АСВ» (разделы «Новости» и «Интерфакс об Агентстве»), RSS финансовых СМИ (banki.ru, «Ъ», РБК, Интерфакс, ТАСС, Лента) с грепом по АСВ/страховому возмещению/отзыву лицензии, затем чтение найденных статей через web_fetch.
