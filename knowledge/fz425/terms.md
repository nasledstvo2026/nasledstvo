# Глоссарий 425-ФЗ

## ПОС (Поручение об отмене/приостановлении операций по счетам)
Документ, направляемый ФНС в банк, для приостановления операций
по счетам налогоплательщика. С 01.01.2027 — без указания конкретного счёта,
банк самостоятельно находит счета должника.

## ПНО (Поручение на оплату / налоговое инкассо)
Документ, направляемый ФНС в банк, для взыскания задолженности
за счёт денежных средств на счетах налогоплательщика.
С 01.01.2027 — без указания конкретного счёта.
SLA: 3 часа на обработку.

## Реестр решений о взыскании задолженности
Единая база решений ФНС. Доступна банкам через REST API.
Заменяет СМЭВ-3 канал обмена документами ПОС/ПНО.

## СМЭВ-3
Система межведомственного электронного взаимодействия.
Текущий канал обмена ПОС/ПНО. Заменяется на REST API.
Старые документы, полученные по СМЭВ-3 до 01.01.2027,
с 01.01.2027 исполняются по новым правилам (ст. 20).

## Розыск счетов
Обязанность банка самостоятельно найти все счета налогоплательщика
для исполнения ПОС/ПНО, включая счета, открытые после поступления документа.

## Очерёдность исполнения (ПНО)
Определяется банком самостоятельно при списании по ПНО
в отношении нескольких счетов одного налогоплательщика.

## SLA
- ПНО: 3 часа (включая доисполнение — перечисление по факту зачисления средств)
- ПОС: 1 операционный день

## Ст. 20 425-ФЗ — Переходный период
Документы, поступившие по СМЭВ-3 до 01.01.2027 и оставшиеся
на доисполнении в банке, с 01.01.2027 подлежат исполнению
в соответствии с новыми требованиями 425-ФЗ.
