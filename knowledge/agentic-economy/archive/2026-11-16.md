# 2026-11-16 · фокус: заработок

🤖 Агентная экономика — 16.11 · фокус: заработок

🎯 **Возможность дня** — «закупочный агент» для среднего бизнеса (закупки 50–500 млн ₽/год): по одной заявке собирает поставщиков, цены и аналоги в таблицу.
Почему сейчас: Эксепто выкатил «Радар» с окупаемостью <3 мес, но только для закупок от 8 млрд ₽/год — сегмент ниже пуст. https://exepto.ru/radar

💵 **Прайс** — Эксепто: ≈2 млрд ₽ экономии/год на 100 млрд ₽ закупок, 6–7% в каждой третьей закупке (exepto.ru/radar).
РФ-рынок автоматизации: пакеты от 2 000 ₽, верхняя граница категории 1 775 000 ₽ (kwork.ru/search?q=n8n); проект «тендеры/документы» ≈ 50–300к ₽ (playbook).

🧩 **Модель** — канал: прямой аутрич в закупочные отделы + партнёры-интеграторы 1С/CRM; чек: пилот 30–50к ₽ → внедрение 150–250к ₽ + 10–20к ₽/мес.
Запуск 2–3 недели: парсинг + LLM + выгрузка xlsx, один человек; маржа 70–85%, минус API и проверка человеком.

🧪 **Проверка за неделю** — 15 писем закупщикам в стройке, металле и оборудовании с примером «карта рынка по вашему ТЗ».
Собрать 1 бесплатную карту по реальной заявке в обмен на 30-мин разбор. Успех: ≥2 согласия на платный пилот 30к ₽.

🇷🇺 **В РФ** — искать поставщиков на русском и в китайском сегменте (как «Радар»), ПД контрагентов не гонять в зарубежные API (152-ФЗ), платежи через ИП с закрывающими.
Ниша: enterprise занят «Эксепто», подписку на агентную среду тестирует «Думейт» (cnews.ru) — SMB-сегмент свободен.

⚠️ **Где не сработает** — при закупках <50 млн ₽/год экономия не покроет чек; продажа «ИИ» вместо экономии в рублях не закрывается.
Карта рынка — это парсинг: ошибка в характеристиках убивает доверие, нужна ручная валидация топ-3 позиций.

📊 **Сигнал рынка** — 88% специалистов и предпринимателей РФ уже используют нейросети, формальные регламенты есть лишь у трети компаний (CNews/МТС Ads, 16.11).
