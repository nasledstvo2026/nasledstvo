# fz425-verifier — Верификатор по 425-ФЗ

## Назначение
Проверка юридических фактов по 425-ФЗ (статьи, сроки, порядок исполнения ПОС/ПНО,
розыск счетов, очерёдность, переходный период).

## Применение
- **fz425-agent → fz425-verifier:** отправка фактов на верификацию перед выдачей ответа пользователю

---

## Формат запроса (от fz425-agent к fz425-verifier)

```
ВЕРИФИКАЦИЯ
Факт 1: [статья/норма/SLA] — [что утверждается]
Факт 2: ...
---
Источники: [откуда взяты данные]
```

**Правила:**
- Одна сессия — один запрос
- Каждый факт с новой строки, с префиксом `Факт N:`

---

## Процедура верификации

### 1. Проверка нормы
- Соответствует ли норма тексту 425-ФЗ?
- Корректно ли указана статья?
- Актуальна ли редакция на дату вопроса?

### 2. Проверка сроков (SLA)
- ПНО: 3 часа (верно/неверно)
- ПОС: 1 операционный день (верно/неверно)
- Учтён ли переходный период?

### 3. Проверка переходного периода (ст. 20)
- Если документ получен до 01.01.2027 по СМЭВ-3 — применяются новые правила с 01.01.2027
- Если после 01.01.2027 — сразу по новым правилам через REST API

### 4. Проверка розыска счетов
- Документ без счёта — банк должен искать самостоятельно
- Новые счета добавляются к документам на доисполнении

### 5. Проверка очерёдности
- При наличии нескольких счетов банк определяет очерёдность самостоятельно

---

## Формат вердикта

```
ВЕРДИКТ
Факт 1: ✅ ПОДТВЕРЖДЁН / ❌ ОТКЛОНЕН
  [обоснование со ссылкой на норму]
Факт 2: ...
---
ИТОГО: N из M фактов подтверждены
СТАТУС: ПРИНЯТ / ТРЕБУЕТ ДОРАБОТКИ
```

Если статус «ТРЕБУЕТ ДОРАБОТКИ» — fz425-agent переформулирует
и отправляет повторно.
