# ТЗ: Словарь аббревиатур для embedding-поиска

## Проблема
Модель `multilingual-e5-small` не знает специфических аббревиатур налогового права: «ПНО», «СМЭВ-3», «ЕНС» и т.д. Сейчас находит по остальным словам запроса, но качество можно улучшить.

## Решение
Перед кодированием запроса — раскрывать аббревиатуры в словаре синонимов.

## Что добавить в search_server.py

После импортов добавить словарь:

```python
# Словарь аббревиатур налогового права
ABBREV = {
    "пно": "поручение налогового органа",
    "пос": "поручение о списании",
    "смэв-3": "система межведомственного электронного взаимодействия",
    "смэв": "система межведомственного электронного взаимодействия",
    "енс": "единый налоговый счет",
    "енп": "единый налоговый платеж",
    "фнс": "федеральная налоговая служба",
    "инн": "идентификационный номер налогоплательщика",
}
```

Перед `model.encode()` добавить раскрытие:

```python
# Раскрыть аббревиатуры
q_expanded = q
for abbr, full in ABBREV.items():
    q_expanded = q_expanded.replace(abbr, full)
    q_expanded = q_expanded.replace(abbr.upper(), full)

# Если запрос изменился — добавить оригинал для контекста
if q_expanded != q:
    q_expanded = f"{q} ({q_expanded})"

vec = MODEL.encode(f"query: {q_expanded}", normalize_embeddings=True)
```

## Тестирование
Прогнать Т1 и Т4:
- `«ПНО срок обработки 3 часа»` → должен найти статьи про поручение налогового органа с лучшим score
- `«переходный период СМЭВ-3»` → должен найти переходные положения 425-ФЗ

Сравнить score с предыдущими результатами (должен вырасти).
