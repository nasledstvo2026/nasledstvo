# AGENTS.md — Феникс (fz425-agent)

## 🚫 Железное правило: НИКОГДА не перезапускай гейтвей

**`systemctl stop`, `systemctl restart`, `systemctl --user stop` — всё это УБИВАЕТ тебя.**

Ты — агент внутри гейтвея. Когда ты делаешь `systemctl stop`, гейтвей падает, и ты падаешь вместе с ним. `start` никогда не выполняется, потому что твой процесс убит. И `Restart=always` не спасает — он не срабатывает на явный `systemctl stop`.

**Hot-reload конфига работает автоматически.** Когда ты меняешь `openclaw.json`, изменения применяются через 1-2 секунды БЕЗ перезапуска. Ты можешь проверить это в логах: `[reload] config hot reload applied`.

**Если КРИТИЧЕСКИ необходимо перезапустить гейтвей** (например, после изменения `models.providers`):
```
bash ~/phoenix/safe-restart.sh
```
Скрипт планирует перезапуск через systemd-run (таймер выживает при остановке), затем делает stop.
⚠️ Это последняя команда в сессии — ты умрёшь вместе с гейтвеем и воскреснешь через 5 секунд.

Но в 99% случаев hot-reload достаточно. Просто измени конфиг и продолжай работать.

## Ограничение сессии

Контекст сессии ограничен: maxChars=64000 на результат инструмента,
aggregateBudgetChars=256000 на сессию. После 2-3 часов активной работы
контекст переполняется — результаты exec/read обрезаются, модель видит
обрывки.

**Правило:** для любой задачи требующей > 3 вызовов инструментов —
используй sessions_spawn с context="isolated":

```
sessions_spawn(
  task="чёткое описание задачи",
  taskName="уникальное-имя",
  context="isolated",
  cleanup="delete"
)
```

Изолированная сессия стартует с чистым контекстом, выполняет задачу
и возвращает результат. Не накапливай историю в main-сессии.

Для лёгких вопросов (< 3 инструментов) работать в main-сессии можно.
