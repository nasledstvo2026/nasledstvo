### Описание предметной области

**Мера социальной поддержки** — установленная законом или иным нормативным актом форма помощи государства гражданам определённых категорий. Мера может быть выражена в деньгах, льготах, услугах или натуральной помощи.

**Уровни законодательства:** меры поддержки устанавливаются на двух уровнях — федеральном и региональном. Для целей агента анализируются оба уровня, с фокусом на региональные меры (федеральные уже покрыты social-consult-agent).

**Категории — динамический список:**
Стартовый набор из трёх категорий, с возможностью добавления новых Ириной через социального консультанта (см. Этап 5):

**1. Люди с инвалидностью**
Базовый документ: Федеральный закон № 181-ФЗ «О социальной защите инвалидов». Меры различаются по группам (I, II, III), есть специфические меры для детей-инвалидов.

**2. Ветераны боевых действий (ВБД)**
Базовый документ: Федеральный закон № 5-ФЗ «О ветеранах». Три категории ВБД (по подпунктам ст. 3).

**3. Участники СВО и члены их семей**
Базовый пакет: указы Президента РФ, федеральные законы о статусе военнослужащих. Категории получателей: мобилизованные, контрактники, добровольцы. Отдельно выделяются меры для детей участников СВО.

**Хранение категорий:** список категорий хранится в `knowledge/research/categories.json`:
```json
{
  "categories": [
    {"id": "invalidy", "name": "Инвалидность", "base_doc": "Федеральный закон № 181-ФЗ «О социальной защите инвалидов»", "subgroups": ["I группа", "II группа", "III группа", "дети-инвалиды"]},
    {"id": "vbd", "name": "Ветераны боевых действий", "base_doc": "Федеральный закон № 5-ФЗ «О ветеранах»", "subgroups": ["пп.1 ст.3 (Афганистан, Сирия и др.)", "пп.2 ст.3 (Чечня и др.)", "пп.3 ст.3 (другие локальные конфликты)"]},
    {"id": "svo", "name": "Участники СВО и члены их семей", "base_doc": "Указы Президента РФ, федеральные законы о статусе военнослужащих", "subgroups": ["мобилизованные", "контрактники", "добровольцы", "дети участников СВО"]}
  ]
}
```

**Источники информации (по региону):**
- Официальный сайт региона (правительство, губернатор)
- Сайт регионального министерства/департамента труда и социальной защиты
- Региональные законы и постановления
- garant.ru, consultant.ru — тексты НПА
- sfr.gov.ru — информация СФР по региону

**Отличие от социального консультанта:** консультант отвечает на конкретные вопросы (SLA 120с). Исследователь собирает полные перечни мер — это многочасовая задача. Целевое время на регион ~10 минут. Если сбор активно идёт — продлевать. Жёсткий cutoff: 30 минут (защита от реального зависания).

**Связь с существующей архитектурой Феникса:**

**Накопительный результат:** каждая следующая версия Excel-файла надстраивается над предыдущей. Изменения маркируются: 🆕 новое / ❌ отменено / ✏️ изменено / ▬ без изменений (см. Этап 4, Подзадача 7).

### Этап 4. Логика работы исследователя

#### Подзадача 0. Архитектурные ограничения
- Требование 13.1: **sessions_spawn ЗАПРЕЩЁН.** Исследователь — одиночный агент. Вся работа (web_search, web_fetch, exec python, Excel) делается в собственном процессе.
- Требование 13.2: **Последовательная обработка — строго 1 регион одновременно.** Параллельные spawn одного агента конфликтуют на session-файле (EmbeddedAttemptSessionTakeoverError).

В этом случае исследователь отправляет команды irina-router'у через sessions_send, роутер выполняет их и возвращает результат.

## 3. Ограничения и правила
<constraints>
- Ограничение 1: НЕ трогать fz425-agent и fz425-verifier — работают штатно
- Ограничение 2: НЕ трогать social-consult-agent и social-verify-agent — работают штатно
- Ограничение 3: Запуск только по триггер-фразе от Ирины (sender_id=739016616). Без cron
- Ограничение 4: Последовательная обработка — строго 1 регион одновременно (архитектурное ограничение: параллельные spawn конфликтуют на session-файле)
- Ограничение 5: НЕ додумывать данные — если поле не найдено, «Не указано в найденных источниках»
- Ограничение 6: НЕ экстраполировать данные с одного региона на другой
- Ограничение 7: Шаблоны читать из файлов перед каждой категорией (не кэшировать между запусками)
- Ограничение 8: Категории читать из `categories.json` при каждом запуске (не хардкодить)
- Ограничение 9: Модель: v4-flash основная, v4-pro fallback
- Ограничение 10: Целевое время на регион ~10 минут. Если сбор активно идёт — продлевать (с записью причины в лог). Жёсткий cutoff: 30 минут (защита от зависания)
- Ограничение 11: Результаты сохранять локально на Фениксе в `knowledge/research/`
- Ограничение 12: Конфигурацию Феникса править через SSH, не через TUI
- Ограничение 13: Перезапуск Феникса — только через safe-restart.sh
- Ограничение 14: Накопительный Excel: не удалять старые данные, только дополнять и маркировать изменения
- Ограничение 15: sessions_spawn ЗАПРЕЩЁН в социальном исследователе — он одиночный агент
- Ограничение 16: Субагенты исследователя запускаются через `sessions_spawn(context="isolated", cleanup="delete")` — relay-паттерн для обхода ограничений изолированного контекста
</constraints>
