Вопрос

«Какой ожидаемый объем требований ФНС с 01.01.2027 через Реестр Решений о взыскании задолженности в сторону банков? В частности в сторону Сбера?»

Ответ консультанта

На текущий момент точных прогнозных цифр объёмов требований ФНС, которые будут загружены в Реестр решений о взыскании задолженности с 01.01.2027, ФНС России официально не публиковала.

📌 Что точно известно

  1. С 01.01.2027 вступает в силу 425-ФЗ от 28.11.2025. Канал обмена ПОС/ПНО меняется с СМЭВ-3 на REST API через Реестр решений.
  2. Все текущие ПОС и ПНО будут мигрированы в новый Реестр. Документы, полученные по СМЭВ-3 до 01.01.2027 и находящиеся на доисполнении, с 01.01.2027 подлежат исполнению по новым правилам (ст. 20 425-ФЗ).
  3. Техническая документация опубликована на nalog.gov.ru → formats_op_01072026.docx (описание форматов REST API, версия 01.07.2026) и regl_integr_01072026.zip (техрегламент интеграции).

🏦 Что это значит для Сбербанка

  • Нагрузка на интеграцию: переход с СМЭВ-3 на REST API Реестра потребует доработки АБС.
  • SLA ужесточается: ПНО — 3 часа (включая розыск счетов!), ПОС — 1 операционный день.
  • Розыск счетов становится обязанностью банка — документы приходят без указания счёта.
  • Старые документы (полученные по СМЭВ-3 до 01.01.2027) с 01.01.2027 также исполняются по новым правилам (ст. 20).
